# Búsqueda de Productos por Voz 🎤

Una aplicación web moderna que permite buscar productos utilizando comandos de voz en español. La aplicación utiliza reconocimiento de voz y procesamiento de lenguaje natural para entender las consultas del usuario y mostrar los productos relevantes.

## Características ✨

- 🎤 Búsqueda por voz en español
- 📱 Diseño responsive y compatible con móviles
- 🔍 Filtrado y ordenación de productos
- 🎨 Interfaz moderna con Tailwind CSS
- ⚡ Desarrollado con React y TypeScript
- 🤖 Integración con OpenAI para procesamiento de lenguaje natural

## Tecnologías Utilizadas 🛠️

- React 18
- TypeScript
- Vite
- Tailwind CSS
- OpenAI API
- Web Speech API
- Axios

## Requisitos Previos 📋

- Node.js (versión 20 o superior)
- npm (incluido con Node.js)
- Navegador moderno con soporte para Web Speech API
- API Key de OpenAI

## Instalación 🚀

1. Clona el repositorio:
```bash
git clone https://github.com/Dioniss97/busqueda-productos-por-voz.git
cd busqueda-productos-por-voz/project
```

2. Instala las dependencias:
```bash
npm install
```

3. Crea un archivo `.env` en la carpeta `project` y añade tu API Key de OpenAI:
```
VITE_OPENAI_API_KEY=tu_api_key_aquí
```

4. Inicia el servidor de desarrollo:
```bash
npm run dev
```

## Uso 🎯

1. Abre la aplicación en tu navegador
2. Haz clic en el botón del micrófono
3. Permite el acceso al micrófono cuando el navegador lo solicite
4. Habla tu consulta (ejemplo: "muéstrame productos de electrónica ordenados por precio")
5. Los resultados se mostrarán automáticamente
